# مطابخ الجنوب للمأكولات الشعبية — نظام نقاط البيع والفواتير الإلكترونية
### Southern Traditional Dishes Kitchens (STDK) — POS & E-Invoicing

نظام نقاط بيع عربي (RTL) لمطعم واحد، يعمل **بدون إنترنت** ويصدر **فواتير إلكترونية رسمية**
تحمل بيانات المنشأة وكود تحقق QR، مع مزامنة سحابية اختيارية ولوحة متابعة للمالك.

---

## المميزات

- **نقطة بيع** — أصناف مقسّمة (وجبات / ولائم / إضافات)، بحث عربي وإنجليزي، تعديل الكمية
  والسعر لكل سطر، خصم ورسوم توصيل، دفع نقدي أو على الحساب.
- **فاتورة إلكترونية رسمية** — بيانات المنشأة كاملة (س.ت، رقم قيد المنشأة، التسجيل الضريبي)،
  رقم مسلسل، معرّف فريد، بصمة تحقق، كود QR، والمبلغ بالحروف. طباعة A5 أو رول حراري 80 مم،
  أو تصدير PDF / ملف HTML مستقل.
- **سجل الفواتير** — بحث وفلترة، تحصيل الآجل، إلغاء بدون حذف (يبقى في السجل)،
  وطباعة **سجل رسمي** للجهات الحكومية + تصدير Excel.
- **تقارير** — عدد الوجبات المباعة، المبيعات حسب القسم، الأصناف الأكثر مبيعاً،
  المبيعات اليومية، مع تقرير مطبوع وتصدير CSV.
- **يعمل بدون إنترنت** — تطبيق مثبَّت (PWA) بقاعدة بيانات محلية (IndexedDB) ولقطات يومية.
- **مزامنة سحابية اختيارية** — Convex؛ نقطة البيع تعمل محلياً دائماً وترفع ما تأخّر
  أول ما يعود الإنترنت.
- **لوحة متابعة للمالك** — صفحة مستقلة تُفتح من الموبايل لمتابعة المبيعات.

## التشغيل

```bash
# الطريقة الأسهل على ويندوز: اضغط مرتين على pos/تشغيل النظام.bat
python -m http.server 8777 --directory pos
```

ثم افتح `http://localhost:8777`.

> يمكن فتح `pos/index.html` مباشرة، لكن تثبيت التطبيق والعمل الكامل بدون إنترنت
> يتطلبان تشغيله من خادم (المتصفح يمنعهما على بروتوكول الملفات).

### المزامنة السحابية (اختيارية)

```bash
npm install
npx convex dev          # ينشر الدوال على نشرتك
npx convex env set SYNC_KEY "<مفتاح-قوي-من-اختيارك>"
```

ثم أدخل رابط النشرة والمفتاح في *الإعدادات ← المزامنة السحابية*.

المفتاح يحمي كل الدوال، لأن دوال Convex العامة قابلة للنداء من أي جهة تعرف الرابط.

## ملاحظات

- **لا اعتمادات خارجية في الواجهة** — لا CDN ولا مكتبات. كود QR والخط مستضافان محلياً
  ليعمل النظام بلا إنترنت.
- **بيانات المنشأة تُحفظ نسخة منها داخل كل فاتورة وقت إصدارها**، فتبقى الفواتير القديمة
  كما صدرت حتى لو تغيّرت الإعدادات لاحقاً — كما يليق بسجل رسمي.
- **الفواتير الملغاة لا تُحذف** أبداً؛ تبقى في السجل بعلامة «ملغاة».
- **ضريبة القيمة المضافة** غير مفعّلة (لم تُطبَّق في قطر بعد)، وجاهزة للتفعيل من الإعدادات.
- **بيانات الاتصال بالسحابة ومستندات المنشأة الممسوحة مستثناة من المستودع** عمداً.
